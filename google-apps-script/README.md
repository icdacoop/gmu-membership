# 구글 시트 연동 설정 방법 (약 5분)

회원 신청이 들어오면 구글 스프레드시트에 한 줄씩 저장됩니다.
**다른 홈페이지(my-homepage 등)의 시트·토큰과 섞이지 않도록 반드시 새로 만드세요.**

1. [sheets.google.com](https://sheets.google.com)에서 **새 스프레드시트**를 만듭니다. 이름은 `GMU 회원신청` 등 자유롭게 정하세요.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용 전체를 붙여넣고 저장합니다.
4. 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 스크립트 속성 추가**에서 값을 등록합니다.
   - `APPLY_TOKEN` : 길고 추측하기 어려운 새 문자열 (아래 명령으로 만들 수 있습니다)
   - `NOTIFY_EMAIL` (선택) : 새 신청 알림을 받을 이메일 (예: gma.one2025@gmail.com)
5. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 처음이면 권한 승인 화면에서 계정을 선택해 허용합니다. (고급 → 안전하지 않음으로 이동 → 허용)
6. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. 프로젝트 폴더의 `.env.local` 파일(`.env.example`을 복사해서 만듭니다)에 입력합니다.
   ```
   GOOGLE_SCRIPT_URL=위에서 복사한 웹 앱 URL
   APPLY_TOKEN=4번에서 정한 값과 똑같이
   ```
8. Vercel의 **Settings → Environment Variables**에도 같은 두 값을 등록하고 다시 배포(Redeploy)합니다.

`APPLY_TOKEN`으로 쓸 문자열 만들기 (PowerShell):

```powershell
[Convert]::ToBase64String((1..32 | ForEach-Object { Get-Random -Maximum 256 }) -as [byte[]])
```

## 코드를 고친 뒤 다시 배포할 때
**배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누르세요. 새 배포를 만들면 주소가 바뀌어 `GOOGLE_SCRIPT_URL`을 다시 고쳐야 합니다.

## 계좌이체(무통장입금) 입금 확인 방법 (운영자)
1. 신청이 들어오면 시트에 **결제수단 = 계좌이체**, **결제여부 = 결제대기**로 한 줄이 생깁니다.
2. 은행 입금 내역에서 **입금자명**(일반회원은 성명, 기업회원은 기업명)과 **금액**(20만 원 / 50만 원)이 맞는 입금을 찾습니다. 접수번호로 신청 행을 찾을 수 있습니다.
3. 입금을 확인하면 해당 행의 **결제여부** 칸(I열)을 눌러 드롭다운에서 **결제완료**를 고릅니다. **결제일시**(K열)는 자동으로 채워집니다.
4. 환불했다면 **환불**로 바꾸고 **메모**(N열)에 날짜를 적어 두세요.

결제여부 칸의 선택지는 `결제대기`, `결제완료`, `결제실패`, `환불` 네 가지만 허용됩니다. (직접 타이핑해도 이 값이 아니면 거절됩니다)

## 기존에 만들어 둔 시트에 적용할 때 (코드 교체 후)
1. Apps Script에 새 `Code.gs`를 붙여넣고 저장합니다.
2. **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누릅니다. (새 배포를 만들면 주소가 바뀝니다)
3. 다음 신청이 들어오면 `결제수단` 머리글(P열)이 자동으로 추가되고 결제여부 드롭다운이 걸립니다. 기존 데이터는 그대로이며, 기존 행의 결제수단 칸은 비어 있습니다.
4. 바로 적용하고 싶다면 Apps Script 편집기에서 함수 `setupSheet`를 선택해 **실행**하세요. (처음 실행 시 권한 승인 필요)

## 시트 열 구성
`접수번호 | 접수일시 | 회원구분 | 성명 | 기업명 | 전화번호 | 이메일 | 관심분야 | 결제여부 | 결제금액 | 결제일시 | 거래번호 | 개인정보동의 | 메모 | 신청언어 | 결제수단`

- `결제수단`은 신청자가 고른 방법(`계좌이체` 또는 `카드`)입니다.

- `신청언어`는 신청자가 사이트를 한국어/영어 중 어느 쪽으로 보고 신청했는지 기록합니다. (영어 신청자에게는 영어로 연락할 수 있습니다.)

- 일반회원의 `성명`은 신청자, 기업회원의 `성명`은 **대표자명**이며 `기업명`이 함께 저장됩니다.
- 새 신청은 `결제여부`가 **결제대기**로 저장됩니다. 결제 연동 후에는 결제 확인이 되면 **결제완료**로 바뀝니다.
- **열을 삭제하지 마세요.** 삭제하면 이후 데이터가 한 칸씩 밀립니다. 보기 싫으면 열 숨기기를 쓰세요.
- `메모` 열은 운영자가 자유롭게 쓰는 칸입니다.
